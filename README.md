# Witold Kaminski

**Principal Software Engineer · Software Architect**

Systems and embedded software engineer with more than 20 years of experience in C/C++ and Linux-based systems. My work spans software architecture, embedded Linux platforms, system integration, build and development infrastructure, and technical leadership.

In parallel to my professional work, I develop tools and experiments in Rust, including AI-assisted software engineering and modular build infrastructure.

## Focus

- **Systems & Embedded Software** — C/C++, Embedded Linux, Linux kernel and kernel modules, Yocto/BitBake, U-Boot, Secure Boot, real-time systems
- **Software Architecture** — system and software architecture, modular platforms, system integration, technical design decisions, code reviews
- **Build & Development Infrastructure** — Git/GitLab, CI/CD, GCC and cross-compilation, build systems, crosstool-ng, build and development automation
- **Additional languages** — Python, Rust, Java

## Selected personal projects
